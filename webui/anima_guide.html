0. 一句话上手

桌面双击 「ComfyUI 一键出图」 → 等右上角显示引擎已连接 → 在正向提示词框里写一句中文（例如 灵梦 后入 吐舌头 全身）→ 点页面上的 生成 → 12～20 秒出图。

出图落在 D:\ComfyUI\output\，文件名形如 anima_pg_00001_.png（WAI 档是 wai_gen_）。要重画手，点「修手」；要看每个词的中文，看输入框下面那行「中文：…」。

3. Anima 的正确参数（别乱调）

参数取值说明
步数10turbo LoRA 是步数蒸馏出来的，10 步是设计工况
CFG1.0关键。CFG 调到 4 会饱和度暴涨、暗部压死，立刻"欧美 CG 塑料感"
采样器 / 调度器er_sde / beta官方 10 步工作流同款
分辨率1024×1536竖图最稳；832×1216 更快但细节少
LoRA 链turbo 1.0 → kinokohime 0.6 → konya 0.3顺序与权重都别动

实测结论（同提示词同种子）：CFG 1 时 10/20/30 步都合格，只是越跑越厚、越暗；CFG 4 的几张明显更差。所以上一轮"效果差"的元凶是 CFG，不是内容。既然三档都合格，就取最省时间的 10 步。

分辨率别贪大：1536×2304 时微对比掉到 51（1024×1536 是 66.8），耗时从 16s 涨到 36s，长边超过 1792 开始发糊。

4. 四种用法

4.1 场景直出（最省事）

页面左侧「标签库 → 场景」里有 187 条我们自己的场景，按 ◆前戏 / ◆插入 / ◆手动 / ◆口交 / ◆多人 / ◆高潮 / ◆事后 分组。点一条，正向框会被填好（含机位、表情、取景），直接点生成。

场景的写法已经包含过"减法"经验，例如后入不会同时写 sex/doggystyle/arched_back（会画出奇怪姿势），乳交不会混进插入词（会穿模）。

4.2 表情档（★T0–T5）

预设里另有 6 条 ★表情 T0–T5，直接写在正向提示词末尾即可：

档语义典型组合
T0原生，不干预不写任何表情词，交给底模
T1温柔 / 高冷 / 羞涩light_smile, blush、expressionless
T2坏笑 / 挑衅smirk, one_eye_closed
T3吐舌 / 喘息 / 泪目tongue_out, half-closed_eyes
T4半崩坏rolling_eyes, drooling
T5失神（只适合事后 / 二次）empty_eyes, parted_lips

口交类不建议用 T0（底模会给一张面无表情的脸，反而怪），用 T2/T3 更自然。

4.3 中文一句话 + 本地扩写（推荐）

在正向框里直接写中文，点生成时脚本会先调本地 planner 把中文翻成 tag，再做规范化，然后提交。写法大致是：

角色 + 动作/体位 + 细节 + 景别 + (可选)画风
灵梦 后入 吐舌头 全身
蕾米 骑乘 侧面看 七分身
魔理沙 口交 含着 脸颊鼓鼓的

实测映射（够用就好，不用背）：

你写的转成
后入sex_from_behind, all_fours
骑乘cowgirl_position, girl_on_top
口交oral, fellatio
乳交paizuri, breast_press
腿交thigh_sex

三条经验：① 一句话里最多两个动作，多了底模会拼错；② 想要脸入画就写「全身」或「七分身」，别写「特写」；③ 精液词只在你真要的时候写，不然满屏都是。

4.4 画师 tag

页面「画师」区有 10 个风格 tag。常用的是 kanpa (campagne 9)（日式厚涂、皮肤干净）、pako (pako)、lack。画师 tag 放最前面，效果比堆形容词明显。

5. 出图之后

  1. 看中文对照：正向框下面那行「中文：…」逐词翻译（3276 条对照表），能立刻看出模型理解偏了哪里。
  2. 修手：点「修手（重画手部）」，只重画手部区域（FaceDetailer，8 步 / denoise 0.45），约 8 秒，其余像素不动。
  3. 不满意怎么改（按性价比排序）：
  • 换种子（最省事）；
  • 改景别（脸被裁 → 改「全身」；人太小 → 改「七分身」）；
  • 删词而不是加词（重复的 sex、互相冲突的机位最容易出事）；
  • 换机位（from_behind / from_side / from_above / from_below 只留一个）。

7. 常见问题

页面一直转圈不出图？ 看控制台的「引擎日志」tab，多半是 ComfyUI 引擎没起来。关掉控制台重开，或等 30 秒再试。

点生成毫无反应（也不报错）？ 历史原因有两个，都已修：① 8199 代理把浏览器 Origin 转给 ComfyUI 会被 403；② 中文正则写错导致不触发扩写。若再遇到，先确认 8199 在跑：curl http://127.0.0.1:8199/system_stats。

图存哪了？ D:\ComfyUI\output\。一键出图前缀 anima_pg_（WAI 档 wai_gen_），修手是 anima_handfix_，插件节点出图是 anima_v5_。

能批量吗？ 能。tools/batch_scenes.py 按 id 批量跑 r18 场景库 187 条，跑完自动生成 INDEX.md 与联系表；角色缩略图批量用 tools/gen_char_thumbs_local.py --limit 2400。

能换别的模型吗？ Anima 这套是固定的（UNET+CLIP+VAE 三者配套）；换底模请用「WAI」按钮那套，或在页面里把 mode 改回 ckpt 模式自己填。

9. 每次开机做什么

  1. 双击「ComfyUI 一键出图」，等右上角变绿（引擎连上）。
  2. 需要换底模就点 Anima / WAI。
  3. 写中文或点场景 → 生成。
  4. 不满意先换种子，再删词，最后才加词。
  5. 收工直接关窗口；服务下次启动会自己补。
