## 1. 这是什么

三件东西合起来：

1. **ComfyUI**：真正出图的引擎（`D:\ComfyUI\ComfyUI_windows_portable`）。
2. **`webui/assistant.py` + `webui/planner.py`**：语义层。把中文拆成槽位、渲染成 danbooru 标签、校验词表、按规则做减法与冲突清理；再拼成 ComfyUI 工作流提交、轮询、回图。
3. **`tools/gen_workbench.py` → `webui/workbench.html`**：单页操作台。四块面板 + 资料库 + 批量出图 + 日志。

设计三原则：

- **Agent 填槽与代码渲染分离**：模型只负责"理解并填槽"，拼串、排序、去重、减法是确定性代码。
- **减法优于堆词**：能不写就不写。后入不写 `sex`、腿交不写 `vaginal`、乳交不写插入。
- **写错不如不写**：词表里没有的写法一律丢（`_drop_unknown`），不赌底模猜得对。

## 5. 分级与规则

### 5.1 三级分级（唯一来源 `_setup/tier_sets.py` → `wb_tiers.json`）

| 等级 | 词数 | 举例 | 出现档位 |
|---|---|---|---|
| **L3** | 149 | `sex / vaginal / penis / cum* / nipples / nude / bondage / tentacles / futanari / ahegao` | 仅 R18 |
| **L2** | 91 | 内衣泳装、露肩、湿衣、吻、乳、`lactation`、衣饰类束缚、`kissing` | 擦边 + R18 |
| **L1** | — | 日常动作与场景 | 全档 |

判定规则（`tierScenes()` / `tierGate()` 同源）：

```
L1 → 可进 SFW      L1+L2 → 可进擦边      全量 → R18
SFW 额外剔 L2 与男性词；擦边额外剔男性词
表情封顶：SFW ≤ T1，擦边 ≤ T2
非 R18 剔：kneeling / all_fours / spread_legs / legs_up / arched_back / nude / saliva
```

体检：`python tools/audit_tiers.py`（`--fix` 按等级修 `group`，只升不降）。

### 5.2 六档表情

| 档 | 语义 | 组合 |
|---|---|---|
| T0 | 原生 | 不写 |
| T1 | 温柔·高冷·羞涩 | `light_smile+blush` / `expressionless` / `closed_mouth+blush` / `shy+blush+looking_away` |
| T2 | 坏笑·挑衅 | `smirk` 四组 |
| T3 | 吐舌·喘息·泪目 | `tongue_out` / `open_mouth+heavy_breathing` / `tears` |
| T4 | 半崩坏 | `rolling_eyes+drooling` / `torogao` |
| T5 | 失神 | `empty_eyes` / `blank_stare` / `dazed`（仅事后或二次） |

`torogao` 已并入 T3 组。UI 的 🎲 抽到的表情是**最终表情**，扩写里的表情词会被剥掉。

### 5.3 常驻减法与冲突清理

| 场景 | 规则 |
|---|---|
| 后入（`sex_from_behind/doggystyle/all_fours`） | 去 `sex/doggystyle/arched_back`；若既无 `vaginal` 也无 `anal` 补 `vaginal` |
| 乳交（`paizuri/breast_press`） | 去插入类词（`vaginal/sex/missionary/cum_in_pussy/deep_penetration`） |
| 口交（`fellatio/oral/cunnilingus`） | 去 `vaginal/sex/cum_in_pussy` |
| 腿交（`thigh_sex`） | 去 `vaginal/sex/leg_lock` |
| 女女（`yuri/tribadism/2girls`） | 去全部男性词与精液词，补 `sweat/pussy_juice` |
| 机制（触手/机械/玩具） | 去全部男性词（`futanari` 保留 `penis`） |
| 扶她 | **禁 `sex`**，用 `penis + vaginal`（正入视角连 `penis` 也不写）；双人补 `futa_with_female` |
| 事後 | 只单人；剔男性词，补 `solo, after_sex` + 精液/爱液 |
| 催眠 | 爱心瞳孔压掉 `empty_eyes` 等空洞眼，补 `torogao + parted_lips`，抬到 `upper_body` |
| 有男性 | 必带 `faceless_male`（`pov` 除外） |
| 名字没写衣服 | 剔全部衣饰词（防"没提裙子却穿 JK 裙"） |
| 打码触发词 | 补 `uncensored`；有 `uncensored` 时负面剔全部 censor 词 |
| 体位互斥 | 主位只留第一个；`legs_together` 与 `spread_legs/legs_up/leg_lift` 互斥 |
| 机位/取景 | 机位只留一个；取景优先级 `pov > cowboy_shot > upper_body > full_body` |
| 词形 | 带空格写法统一收敛到词表合法 tag；词表没有的一律丢 |

扫一遍：`python tools/audit_conflicts.py`（数据 + 规则引擎）、`python tools/audit_names.py`（名字与标签一致）、`python tools/audit_male_leak.py`（机制场景混男性）。

## 6. 批量出图

- 选好角色（可多选）+ 服饰 + 画师 → 设张数（1–60）→ 一键批量。
- 六档递进：`前戏(T1) → 暧昧(T2) → 插入(T3) → 激烈(T4) → 高潮(T4) → 事后(T5)`，每张自动换场景与表情。
- 档位即上限：SFW 只走 L1 场景、表情封顶 T1；擦边走 L1+L2、封顶 T2。
- `暂停` 在当前张完成后停；`清空` 归零标签/角色/服饰/人数词（含归属表，不会串角色）。
- 每张的档位、角色、前几词写入 `logs/workbench.log`。

## 7. 出图后处理

| 功能 | 做法 |
|---|---|
| 修手 | `FaceDetailer`：8 步 / CFG 1 / `er_sde+beta` / denoise 0.45 / guide 384 / max 768；检测不到手则直通 |
| 对话框 | 参数行勾选「对话框」→ 追加 `speech_bubble` |
| 放大 | 生成时用「7 步放大」档（1.35×，再做一次低 denoise 细化） |
| 重跑 | 「重跑上一张」回填提示词 + 参数 + 种子 |

打码处理：正面出现 `uncensored` 时，负面里的 censor 类词会被自动剔除（实测这套组合最稳）。

## 8. 参数速查

| 底模 | 步数 | CFG | 采样 | 调度 | 分辨率 | 耗时 |
|---|---|---|---|---|---|---|
| Anima 12 | 10 | 1.0 | `er_sde` | `beta` | 1024×1536 | 9–18s |
| Anima 12 | 10 | 1.0 | 同上 | 同上 | 832×1216 | 7–9s |

Anima 要点（实测）：CFG 是画风漂移主因（1→4 饱和度 +136%、对比 +25%）；turbo 是步数蒸馏 LoRA，10 步是设计工况；长边 > 1792 微对比掉 24%、耗时翻倍；`VAEDecodeTiled` 512/64 防 15.8GB 内存下 `Fatal Python error: Aborted`。

## 9. 故障速查

| 现象 | 原因 / 处理 |
|---|---|
| 页面点生成无反应 | 代理没起（8199）或 ComfyUI 对带 `Origin` 请求回 403 → 重启 `comfy_proxy.py` |
| `/api/gen` 报 `value_smaller_than_min` | 种子传了 -1 给 KSampler → `gen_graph` 已改时间戳，若复发检查前端 |
| 图里出现马赛克 | 正面缺 `uncensored`；或负面里塞了裸 `censored` |
| SFW 跑出露骨内容 | 该 tag 未进 `wb_tiers.json` 的 L3 → 补词并重跑 `tier_sets.py --apply` |
| 换角色后两个人一起出现 | `清空` 没清归属表（v3 已修）；否则查 `S.userTags` |
| 场景名显示 `(无名)` | 该条只有 `zh` 或只有 `name_zh`，页面已兜底，仍空则数据缺名 |
| 缩略图空白 | `presets/thumbs/<tag>.webp` 不存在；跑 `gen_char_thumbs_local.py --only-tag` |
| 手部崩 | 点「修手」；或在提示词里避免双手交叠 |
| 扩写卡住 | `EXPAND_LLM_TIMEOUT`（默认 20s）后走 rule-only，`_model` 会显示 `rule-only` |
| 出图内存爆 | 确认 `VAEDecodeTiled` 在位（512/64/64/8） |
